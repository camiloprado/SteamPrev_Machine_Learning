# Referencial Teorico e Artigo do TCC

## Escopo

Este documento organiza a base academica do projeto e a estrutura prevista para o artigo final.

Projeto: Previsor Steam  
Autor: Camilo Prado  
Curso: Ciencia da Computacao

## Problema de pesquisa

Como usar dados publicos de jogos da Steam para prever sinais de desempenho de mercado (ex.: direcao de preco, reviews e comportamento de promocao) com um pipeline reproduzivel de dados e machine learning.

## Objetivo academico

- construir pipeline de coleta e tratamento em escala
- treinar e comparar modelos supervisionados
- analisar limites, vieses e utilidade pratica dos resultados

## Estrutura do artigo (proposta)

1. Introducao
2. Fundamentacao teorica
3. Metodologia
4. Resultados e discussao
5. Ameacas a validade
6. Conclusao e trabalhos futuros
7. Referencias

## Fundamentos utilizados

### Machine Learning
- aprendizagem supervisionada para classificacao e regressao
- engenharia de atributos em dados tabulares e semiestruturados
- avaliacao com metricas de classificacao e erro de regressao

### Engenharia de dados
- coleta assíncrona com tolerancia a falhas
- ETL para padronizacao de registros heterogeneos
- controle de execucao por checkpoint

### Banco de dados
- modelagem relacional para operacao e analise
- consultas otimizadas para alto volume
